    Play together

    Both of you defend the same map from your own side of it. There is no server — you swap two codes to connect, and after that the game talks directly between the two computers.

    1Your invite code
    Press Create, then send this whole block to the other player however you like — chat, email, a text.
    2Their reply code
    Paste what they send back, then start. The round begins on both screens at once.
    1Their invite code

    2Your reply code
